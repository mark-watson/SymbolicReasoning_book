# The Neurosymbolic Paradigm - Examples

This directory contains example code and demonstrations for Chapter 5, covering:

- **Why Deep Learning Alone is Insufficient**: Demonstrations of neural network limitations in reasoning tasks
- **Neural-Symbolic Integration**: Hybrid architectures combining neural perception with symbolic reasoning
- **Differentiable Reasoning**: Soft logic, fuzzy unification, and differentiable inference
- **Case Studies**: Problems where neurosymbolic methods outperform purely neural or purely symbolic approaches

These examples use Racket Scheme with the Malt library to show how neural and symbolic methods can be combined within a unified Lisp environment.
