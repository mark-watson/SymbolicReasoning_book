# Neurosymbolic Architectures & Algorithms - Examples

This directory contains example code and demonstrations for Chapter 6, covering:

- **Logic Tensor Networks (LTN)**: Tensor-based implementations of first-order logic with differentiable reasoning
- **Logical Neural Networks (LNN)**: Neural networks structured to encode logical formulas
- **NeurASP**: Integration of Answer Set Programming with neural network training
- **Differentiable ILP (∂ILP)**: Neural implementation of inductive logic programming

These examples use Racket Scheme with the Malt library to implement core neurosymbolic architectures, demonstrating how neural learning and symbolic reasoning can be unified in a single framework.
