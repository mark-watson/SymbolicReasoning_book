# The Program Synthesis Problem - Examples

This directory contains example code and demonstrations for Chapter 2, covering:

- **Problem Formulation**: `04-problem-formulation.rkt` - Formal definition of synthesis problems with specifications and verification
- **Enumerative Search**: `01-enumerative-search.rkt` - Bottom-up and top-down program enumeration with pruning
- **Version Space Algebras**: `02-version-space-algebras.rkt` - Compact representation and operations on consistent hypothesis spaces
- **Stochastic Search**: `03-stochastic-search.rkt` - Genetic programming for program evolution
- **Applications**: Data wrangling, code repair, and scientific discovery scenarios

These examples use Racket Scheme to demonstrate how synthesis problems are formally defined and explored using various search strategies.

## Running the Examples

```bash
racket 01-enumerative-search.rkt
racket 02-version-space-algebras.rkt
racket 03-stochastic-search.rkt
racket 04-problem-formulation.rkt
```

Each example implements a core technique for solving program synthesis problems, preparing you for the more advanced methods in later chapters.
