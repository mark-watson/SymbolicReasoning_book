# The Program Synthesis Problem - Examples

This directory contains example code and demonstrations for Chapter 2, covering:

- **Problem Formulation**: Defining synthesis problems with specifications, examples, and constraints
- **Specification Languages**: Ways to express user intent, from formal logic to input-output examples
- **Deductive vs. Inductive Synthesis**: Comparing approaches that derive versus infer programs
- **Applications**: Data wrangling, code repair, and scientific discovery scenarios

These examples use Racket Scheme to demonstrate how synthesis problems are formally defined and categorized.
