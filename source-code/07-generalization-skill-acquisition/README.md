# Generalization & Autonomous Skill Acquisition - Examples

This directory contains example code and demonstrations for Chapter 7, covering:

- **Generalization Beyond Training**: Techniques for systematic and compositional generalization
- **Compositional Abstractions**: Library learning and macro discovery for reusable program components
- **Test-Time Adaptation**: Online synthesis and few-shot learning in new domains
- **Autonomous Skill Acquisition**: Discovery, composition, and refinement of skills without human intervention

These examples use Racket Scheme to demonstrate how synthesis systems can learn to learn, building repertoires of reusable knowledge.
