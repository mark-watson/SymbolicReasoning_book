# Appendix: Essential Tools & Resources - Examples

This directory contains example code and demonstrations for the Appendix, covering:

- **SMT Solver Integration**: Examples using Z3 and CVC5 from Racket Scheme
- **Neurosymbolic Frameworks**: Implementations and usage patterns for LTN, LNN, and NeurASP
- **Utility Libraries**: Helper functions for program representation, manipulation, and evaluation
- **Further Reading**: Curated lists of papers and resources for deeper exploration

These examples provide practical starting points for building your own synthesis systems using the tools and frameworks discussed throughout the book.
